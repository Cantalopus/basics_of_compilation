| Directive  | Literal meaning                         |
| ---------- | --------------------------------------- |
| `#include` | **include**                             |
| `#define`  | **define**                              |
| `#undef`   | **undefine**                            |
| `#if`      | **if**                                  |
| `#ifdef`   | **if defined**                          |
| `#ifndef`  | **if not defined**                      |
| `#elif`    | **else if**                             |
| `#else`    | **else**                                |
| `#endif`   | **end if**                              |
| `#error`   | **error**                               |
| `#warning` | **warning**                             |
| `#pragma`  | **pragmatic information / instruction** |
| `#line`    | **line**                                |
